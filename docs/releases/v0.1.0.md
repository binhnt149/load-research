# Load Research Desktop 0.1.0

Bản **thử nghiệm** đầu tiên cho quy trình nghiên cứu phụ tải cục bộ. Cung cấp mã nguồn và Python wheel; chưa có bộ cài độc lập Windows/macOS.

## Chức năng

- Nhập CMIS mẫu, MDMS, tổng điện năng thương phẩm tháng và lịch từ tệp; ánh xạ cột, khai báo đơn vị/kỳ/hệ số rõ ràng.
- Ghép và làm sạch dữ liệu, bù có giới hạn và truy vết; trung bình từng khách hàng, phân cụm K-Means/DBSCAN, tổng hợp và suy rộng theo tháng.
- Xem biểu đồ chung cùng thành phần hành vi theo ngành/tháng/loại ngày; chọn kW/kWh, Q/U/V và 24/48 chu kỳ.
- Xuất CSV/XLSX/PNG/SVG, lưu cấu hình/phương pháp/checksum, so sánh run và sao lưu dự án.

## Tệp phát hành và cài đặt

Tải wheel và `SHA256SUMS` tại [GitHub Release](https://github.com/binhnt149/load-research/releases/tag/v0.1.0). Mã nguồn ở mục Source code của cùng release. Wheel chứa mã Python của ứng dụng; pip sẽ cài các thư viện phụ thuộc, gồm Qt.

Yêu cầu Python **3.12**, môi trường ảo mới và thư mục dự án có quyền ghi. Sau khi tải wheel vào thư mục hiện tại:

macOS:

```bash
shasum -a 256 -c SHA256SUMS
python3.12 -m venv .venv
.venv/bin/python -m pip install ./load_research-0.1.0-py3-none-any.whl
.venv/bin/python -m load_research
```

Windows PowerShell:

```powershell
Get-FileHash .\load_research-0.1.0-py3-none-any.whl -Algorithm SHA256
# Đối chiếu với SHA256SUMS trước khi cài.
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install .\load_research-0.1.0-py3-none-any.whl
.venv\Scripts\python -m load_research
```

Muốn dùng đúng các phiên bản đã kiểm tra trên macOS, tải `requirements.lock`, cài bằng `python -m pip install -r requirements.lock` rồi cài wheel với `--no-deps`. Lock gồm cả công cụ phát triển; chưa được xác nhận trên máy Windows sạch.

## Kiểm thử

Từ source checkout và môi trường theo [README](../../README.md):

```bash
python -m pytest -q
python -m ruff check src tests packaging
python -m ruff format --check src tests packaging
python -m mypy src/load_research
python -m build --wheel --no-isolation
```

Trước phát hành: **133/133 test pass**, không fail/error/skip; Ruff/mypy pass. Wheel được kiểm tra nguồn, cài/import và chạy CLI demo. Cocoa desktop đã mở dự án tổng hợp thực trên macOS. Xem [báo cáo kiểm chứng](../verification/final.md).

Benchmark thực 7.000 khách hàng × tháng 01/2025, 10.416.000 giá trị: xử lý/xuất 565,675 giây, RSS đỉnh 0,960 GiB trên macOS arm64, RAM 16 GiB. Không suy diễn thành kết quả đủ 12 tháng.

Kiểm tra thủ công: tạo demo bằng CLI trong README, mở dự án, chọn ngành/loại ngày, chuyển 48→24 và kW↔kWh, xem thành phần, xuất bảng/hình, sao lưu rồi mở bản sao. Dữ liệu demo được sinh tại máy, không kèm dữ liệu khách hàng thật.

## Giới hạn và khôi phục

- E01: cần xác nhận adapter/ngữ nghĩa với tệp CMIS/MDMS thực và UAT của đơn vị.
- E02: chưa có bộ cài không cần Python và chưa nghiệm thu trên Windows/macOS sạch. Các lệnh Windows là hướng dẫn cài đặt dự kiến.
- E03: benchmark đủ 7.000 khách hàng × 12 tháng chưa chạy do thiếu dung lượng trống ở preflight; mục tiêu hiệu năng đủ năm chưa nghiệm thu.
- Chưa suy luận sai số/độ tin cậy toàn tổng thể khi không có hồ sơ thiết kế mẫu; chọn mẫu mới dành cho giai đoạn sau.
